# OBJ-004: Migrar backend generado de hexagonal horizontal a vertical slice

- Fecha: `2026-10-08`
- Estado: `activo`
- Carpeta de entregables: `docs/deliverables/obj-004/`

## Problema / motivo
- El generador hoy produce estructuras con hexagonal horizontal.
- Se requiere migrar a vertical slice, por feature.
- Hacerlo ahora alinea el generador con la estructura objetivo del workspace.

## Alcance
- Incluye:
  - Modificar únicamente los templates del generador; el código fuente del generador queda igual.
  - Los proyectos backend generados se generan en vertical slice.
  - Extraer los dominios Suscription, Quiz, Ai, Parameter.
  - Crear ADR que formalice la estructura propuesta.
  - Abstraer a common el código agnóstico al feature: conexiones, creación de beans,
    infraestructura reusable.
  - Carpetas y archivos solo si el microservicio los usa; sin SOAP si no se usa SOAP.
- No incluye:
  - Cambios en el código fuente del generador.
  - Migrar a vertical slice proyectos ya generados.

## Requisitos y restricciones
- Naming: `domain`, `usecase`, `module` en PascalCase.
- Estructura por feature:
  - `{domain}\{usecase}\domain\{module}Command (record)`
  - `{domain}\{usecase}\application\{module}Handler`
  - `{domain}\{usecase}\infrastructure\rest\{module}Controller`
  - `{domain}\{usecase}\infrastructure\rest\{module}RequestDto`
  - `{domain}\{usecase}\infrastructure\rest\{module}ResponseDto`
- Paquetes sin nivel `modules` (D87, 2026-10-09): `{domain}.{usecase}.<capa>`.
- Configuración transversal: `Configuration` en common, no por feature.
- El generador sigue siendo la única fuente de verdad.
