# Questions

Una duda abierta por archivo: `question-NNN.md` (`QUESTIONS_OPEN`), siguiendo `QUESTION_TEMPLATE`.

**Una duda resuelta no se queda aquí.** Cuando la respuesta es una decisión con consecuencias, se registra como ADR en `DECISIONS` (`NNNN-slug.md`, índice en `DECISIONS_INDEX`) y el ADR cita `question-NNN.md` en su campo `Origen:`. Si la respuesta no es una decisión, la duda se borra: el hilo queda en el entregable y en la decisión que lo citaba.
