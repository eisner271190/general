# general

Repositorio raíz que contiene herramientas y plantillas para generar proyectos y componentes.

Descripción
-----------
Este repositorio agrupa un generador .NET, plantillas de componentes y ejemplos de proyectos.

Estructura destacada
- `generator/` — aplicación .NET que construye planes de generación.
- `components/` — plantillas y defaults para backends y frontends.
- `projects/` — ejemplos y planes de generación por proyecto.

Requisitos
- .NET 9 SDK (u otra versión compatible con los targets del proyecto).

Uso rápido
-----------
Compilar el generador:

```bash
cd generator
dotnet build
```

Ejecutar el generador:

```bash
dotnet run --project Generator.csproj
```
